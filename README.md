
# Customer Segmentation UI

A customer segmentation landing page UI built with React and Tailwind CSS. This project focuses on frontend UI design, component-based architecture, and styling practice.

## Overview

This project presents different customer segments through image-based cards with descriptions and styled buttons. It was created as a frontend practice project while learning React and Tailwind CSS.

## Tech Stack

- React
- JavaScript
- Tailwind CSS

## Concepts Practiced

- Component-based architecture
- Feature-based design
- Atomic Design principles
- Props and Props Drilling
- Array `map()` for dynamic rendering
- Flexbox layouts
- Tailwind CSS styling

## Project Status

- UI design: Completed
- Responsive design: Not implemented
- Functionality: Not implemented

## Purpose

The purpose of this project is to practice React component architecture, passing data through props, dynamic rendering, and UI development using Tailwind CSS.
